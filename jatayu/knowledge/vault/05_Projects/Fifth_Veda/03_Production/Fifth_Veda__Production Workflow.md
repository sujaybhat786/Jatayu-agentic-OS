# Production Workflow

The production process moves through a fixed sequence for every piece of content[cite: 7]. Each stage assumes the prior stage's approval gate has already been cleared; no stage is designed to independently re-verify work from an earlier gate[cite: 7].

## The Pipeline

1.  **Research Approved:** The pipeline strictly requires a completed, signed-off Research Brief before production initiates[cite: 7].
2.  **Story Planning:** Topic is pulled from the Master Content Pool, and a structural Framework and Hook type are assigned based on the audience and evidence type[cite: 12].
3.  **Script Development:** The script is drafted backward, beginning with the Weapon Line, and assembled into the 4-beat short-form structure[cite: 12].
4.  **Visual Direction:** Visual requirements are mapped. Recurring elements (characters, artifacts, environments) are identified for the generation process[cite: 12].
5.  **AI Generation (Google Omni):** 
    *   *Stage 1:* Generate, approve, and lock reference stills (Ingredients)[cite: 12].
    *   *Stage 2:* Generate motion shots using 4-element prompts directing the model to act exclusively on locked Ingredients[cite: 12].
6.  **Editing:** Assembly of generated shots, narration, and on-screen typography following strict shot rhythm parameters[cite: 12].
7.  **Review:** Execution of the Quality Assurance pass against a fixed checklist[cite: 7, 12].
8.  **Publishing:** Final metadata preparation and cross-platform deployment[cite: 7].
