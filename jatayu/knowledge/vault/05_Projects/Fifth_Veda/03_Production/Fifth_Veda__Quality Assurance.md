# Quality Assurance

Every finished script and its paired visual assembly must pass a fixed set of checks before publishing[cite: 7]. A piece that fails any one of these checks is returned for revision[cite: 7].

## The Condensed Short-Form QA Checklist

1.  **Hook Test**
    *   *Check:* The first 3 seconds must contain a number, name, or date[cite: 12].
    *   *Check:* The video must make sense if muted, relying solely on on-screen text[cite: 12].
2.  **One-Stat Discipline (Narrative Review)**
    *   *Check:* The Body beat must not carry more than one statistic or more than one named source[cite: 12].
3.  **Pitfall Test (Editorial Review)**
    *   *Check:* The Twist must produce a genuinely bigger fact than the Body[cite: 12]. A restated fact or a recap fails this test[cite: 12].
4.  **Weapon Line Test (Historical/Consistency Review)**
    *   *Check:* The Epic Ending sentence must be screenshot-worthy[cite: 12].
    *   *Check:* It must not hedge with "perhaps" or "maybe"[cite: 12].
    *   *Check:* It must explicitly credit the Indian source[cite: 12].
5.  **Brand/Anti-Pattern Test (Visual Review)**
    *   *Check:* No visual anti-patterns (cartoon illustration, tourist gloss, ancient aliens aesthetic, AI-generated faces for real historical figures) are present[cite: 12].
    *   *Check:* Colour grade and typography strictly adhere to the brand constants[cite: 12].

## Publishing Approval
The QA reviewer (human) holds veto power[cite: 11]. If an asset fails the checklist and cannot be corrected, it is held and rescheduled[cite: 11]. Never publish a failing episode to meet a deadline[cite: 11].
