# The Fifth Veda: Production Knowledge Pack

## Purpose of this Folder
This directory serves as the permanent Production Knowledge Pack for the JATAYU AI Operating System. It defines the operational engine that transforms verified academic research into high-velocity, cinematic short-form documentary assets. This layer dictates *how* production is executed, establishing immutable workflows, structural script parameters, visual generation pipelines, and quality assurance gates.

## Knowledge Relationships
The production layer does not generate its own underlying truth; it inherits it.
*   **Inheritance from Foundation:** Relies on `[[Brand Identity]]` and `[[Content Philosophy]]` to define the baseline aesthetic and format constraints.
*   **Inheritance from Research:** Relies completely on the output of the `[[Research Workflow]]`. No production initiates without a signed-off Research Package[cite: 7]. The production engine is subtractive, compressing deep research into an irreducible short-form argument[cite: 7].
