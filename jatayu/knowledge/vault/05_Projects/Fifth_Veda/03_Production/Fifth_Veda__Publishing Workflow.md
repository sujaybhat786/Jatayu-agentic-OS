# Publishing Workflow

## Publishing Readiness
Publishing cadence is set to sustain the quality standard indefinitely, not to maximize short-term volume[cite: 7]. Cross-platform distribution reuses the exact same underlying research and script asset across formats[cite: 7].

## Metadata Preparation
*   **Captions/Description:** Must contain the Weapon Line restatement, the primary source/academic citation, and a link to the full episode or related pillar content[cite: 12].
*   **Hashtags:** Use exactly 8 hashtags mapped to the specific content pillar[cite: 11].

## Thumbnail Philosophy
Thumbnails follow a strict architectural template:
*   **Dominant Visual:** One single cinematic image (e.g., manuscript, temple, split screen). No cluttered collages[cite: 11].
*   **Headline Text:** Maximum 5 words, using Montserrat Bold, left-aligned or centered, filling approximately 30% of the thumbnail width[cite: 11].
*   **The Stat Thumbnail:** For data-heavy episodes, place the shocking number directly as the thumbnail text (e.g., "$45 Trillion")[cite: 11].

## Knowledge Feedback Loop
Following publication, performance metrics (CTR, retention drops in the first 30 seconds, Weapon Line reshares) are gathered to adjust future hook strategies and framework selection[cite: 11].
